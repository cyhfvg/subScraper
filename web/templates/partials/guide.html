User Guide

Launching targets

  • Enter a domain like example.com or use a wildcard suffix such as example.* to fan out across configured TLDs. Configure the allowed TLD list under Settings → Wildcard TLDs.
  • Prefix with *. to scan a sub-scope, e.g., *.apps.example.com will recurse under that subdomain while still honoring wildcard TLD expansion when paired with .*.
  • Provide a wordlist path if you want ffuf vhost brute-forcing; leave it blank to skip ffuf automatically.

Templated tool flags

Each tool runs with built-in safe defaults. Any text you add in the Command templates settings will be appended to the underlying command after placeholder expansion. Leave a template blank to keep defaults.

Supported placeholders are replaced per run: $DOMAIN$, $SUBDOMAIN$, $WORDLIST$, $OUTPUT$, $OUTPUT_JSON$, $OUTPUT_PREFIX$, $INPUT_FILE$, $TARGET_URL$, $TARGETS_FILE$, $OUTPUT_DIR$, $DB_PATH$, $THREADS$, and $HOST_HEADER$.
