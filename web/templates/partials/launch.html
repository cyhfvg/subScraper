Quick Tips

  • Domain: DNS brute (dnsx) then port scan, live probe, vhost, screenshot, nuclei/nikto.
  • IP or CIDR: skip DNS brute, nmap service scan, then the web pipeline.
  • Set intranet DNS resolvers in Settings. Public DNS is usually unreachable.
  • Provide a wordlist for DNS brute and Host-header vhost enum.
  • Jobs queue when worker slots are full.
