🔑 API Keys Configuration

Configure API keys for enhanced subdomain enumeration. Most tools work without API keys, but adding them significantly improves results and rate limits.

ℹ️ Important Information

  • API keys are stored in tool-specific config files
  • Amass keys: ~/.config/amass/config.ini
  • Subfinder keys: ~/.config/subfinder/provider-config.yaml
  • After saving keys, restart any active scans to apply changes

Amass API Keys

Amass supports multiple data sources for passive subdomain enumeration.

Shodan FREE TIER

Search engine for Internet-connected devices. Free tier: 100 queries/month. → Get key

VirusTotal FREE TIER

Analyzes files and URLs for malware, includes passive DNS. Free tier: 4 requests/minute. → Get key

SecurityTrails FREE TIER

DNS and domain intelligence platform. Free tier: 50 API calls/month. → Get key

Censys FREE TIER

Internet-wide scanning and certificate data. Free tier: 250 queries/month. → Get key

PassiveTotal (RiskIQ) FREE TIER

Threat intelligence platform with passive DNS. Free community edition available. → Get key

BinaryEdge PAID ONLY

Cybersecurity data platform. Starting at $10/month for 10,000 queries. → Get key

BeVigil FREE TIER

Mobile app security platform with OSINT API. Free tier available with rate limits. → Get key

Subfinder API Keys

Subfinder aggregates data from multiple passive sources. Note: Shodan, VirusTotal, Censys, SecurityTrails, PassiveTotal, and BinaryEdge use the same keys as configured above.

GitHub Personal Access Token FREE

Search GitHub code for subdomain mentions. Rate limits: 5,000 requests/hour. → Create token

Permissions needed: public_repo (or repo for private repos)

💡 Pro Tips
  • Start with free tiers - you can discover many subdomains without paying
  • Shodan, VirusTotal, and SecurityTrails offer the best value for free tiers
  • GitHub token is completely free and very useful for finding subdomains in code
  • Combine multiple free sources for comprehensive coverage
  • Consider paid plans only if you're doing high-volume scanning regularly
